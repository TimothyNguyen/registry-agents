# Figma MCP

Figma MCP configuration for design context, selected-frame code generation,
design-system workflows, and approved canvas operations.

- Remote endpoint: `https://mcp.figma.com/mcp`
- Local Desktop endpoint: `http://127.0.0.1:3845/mcp`

Use the local Desktop endpoint for sensitive corporate design work when its
feature set is sufficient. Keep write operations approval-gated.
